# Ingreso solo con Google y solo por invitación

ReFillr es para la familia y amigos de Luciano, no un servicio abierto. Se entra únicamente con una
cuenta de Google, y Supabase rechaza el alta de cualquier email que no haya sido invitado antes, así un
desconocido no puede crear una cuenta aunque tenga Google. Se descartó email y contraseña (más pantallas,
mails de confirmación con el límite bajo del SMTP gratuito de Supabase) y el registro abierto.
